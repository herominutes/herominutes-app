## Executive Summary

## Our Solution

### 7-Specialist Multi-Agent AI System

Every recovery plan is generated by consulting 7 AI medical specialists, each bringing world-class expertise:

| Specialist | Focus Area | Credentials |
|------------|------------|-------------|
| **Cardiologist** | Cardiovascular safety, exertion limits | Harvard/Mayo Clinic trained |
| **Neurologist** | Neuromuscular patterns, proprioception | Athletic neurologic safety |
| **Orthopedic Surgeon** | Structural integrity, surgical protocols | Olympic/pro team experience |
| **Kinesiologist** | Movement science, biomechanics | Elite athlete analysis |
| **Physical Therapist** | Rehabilitation protocols | Sports rehab specialist |
| **Sports Coach** | Performance, conditioning | Pro athlete coaching |
| **Care Coordinator** | Plan synthesis, safety integration | Interdisciplinary coordination |

### 5-Phase Progressive Recovery Structure

Each phase is 2 weeks, creating a structured 10-week journey:

| Phase | Focus | Duration |
|-------|-------|----------|
| **1** | Protection & Initial Healing | Weeks 1-2 |
| **2** | Controlled Mobility & Activation | Weeks 3-4 |
| **3** | Strength & Stability Building | Weeks 5-6 |
| **4** | Power & Endurance Development | Weeks 7-8 |
| **5** | Return to Function & Performance | Weeks 9-10 |

## Clinical Credibility Features (MVP Complete)

### 1. Liability Waiver with Touch Signature
- Legal protection through digital signature capture
- Scroll-to-read requirement ensures user acknowledgment
- Stored securely in Supabase with timestamp

### 2. Clinical Summary Dashboard
- 7-Specialist analyses with personalized assessments
- Summary bullets in plain language for patient understanding
- Red flags and safety precautions prominently displayed
- Collapsible specialist insights for detailed review

### 3. Evidence-Based Sources Section
- **6-Level Evidence Hierarchy**:
  - Clinical Guidelines (highest)
  - Meta-Analyses
  - Peer-Reviewed Studies
  - Institutional Research
  - Professional Standards
  - Educational Resources
- Each source includes `planConnection` explaining how it informed the specific plan
- Real, verifiable URLs to trusted medical organizations

### 4. Conflict Resolution System
- **4-Tier Priority Hierarchy** embedded in AI prompts:
  1. Safety Specialists (Orthopedic, PT, Cardiologist) - HIGHEST
  2. Medical/Rehabilitation (Neurologist, healing timelines)
  3. Performance Specialists (Kinesiologist, Coach)
  4. Care Coordinator (synthesis with conservative defaults)
- Ensures patient safety when specialist recommendations conflict
- *Technical approach*: Rules injected into Gemini prompts; AI follows hierarchy during generation

### 5. Age-Specific Exercise Guidelines
- **4 Age Cohorts** with tailored modifications:
  - Young (<30): Standard progression, higher intensity tolerance
  - Adult (30-50): Mobility focus, joint-friendly modifications
  - Mature (50-65): Extended warm-ups, lower-impact alternatives
  - Senior (65+): Balance priority, chair-supported options, fall prevention
- Robust age detection from intake form or notes field
- *Technical approach*: Age cohort detected and guidelines injected into AI prompts

### 6. Pain Tracking & Flare-Up Detection
- Pre/post session pain monitoring (0-3 scale)
- Automatic regression recommendations when pain increases
- Pain event logging for pattern analysis

### 7. Progress Persistence
- Session, round, and plan progress saved to Supabase
- Cross-device resume capability
- Row-Level Security (RLS) for data isolation

## Technology Stack

### Architecture
- **Frontend**: React 18, TypeScript, Vite, TailwindCSS, shadcn/ui
- **Backend**: Supabase Edge Functions (Deno runtime)
- **Database**: PostgreSQL via Supabase with RLS
- **AI Engine**: Google Gemini 2.0 Flash with tiered fallbacks
- **Authentication**: Supabase Auth (Email OTP)

### AI Tier Architecture
1. **Gemini 2.0 Flash** - Primary, high-quality generation
2. **Gemini 2.5 Flash Lite** - Faster fallback
3. **DeepSeek Chat** - Cost-effective backup
4. **Algorithmic Fallback** - Local exercise library generation

### Security & Compliance
- API keys stored exclusively in Supabase Edge Function secrets
- No secrets in version control or frontend
- Row-Level Security on all database tables
- HIPAA-ready architecture (enterprise tier)
